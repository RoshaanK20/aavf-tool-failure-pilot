**Title:** Risk-Aware Adaptive Verification for Tool-Using Agents: A Controlled Simulation of Silent Errors and Ambiguous State Changes

**Author:** Roshaan Ahmed Khan

**Affiliation:** BS Artificial Intelligence (BSAI), Sindh Madressatul Islam University, Pakistan

**Description:** This preliminary working paper evaluates four scripted tool-verification policies under controlled, synthetic inventory faults. Across 1,600 seeded scenarios, selective verification improved end-to-end simulated task success compared with accepting all tool outputs, but was less accurate than full verification with an idealized audit service. The study is accompanied by reproducible Python code, synthetic inputs, and paired-bootstrap analysis. It does not evaluate a live LLM agent, establish production reliability, confirm a novel method, or claim peer review. The planned next stage is evaluation with model-generated tool calls and stronger fault models.
