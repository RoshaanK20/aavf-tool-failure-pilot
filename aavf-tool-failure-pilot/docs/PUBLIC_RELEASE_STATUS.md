# Exact status for Working Paper v1.0

**Conducted:** 1,600 synthetic scripted scenarios, matched across four fixed policies; 6,400 outcomes; paired bootstrap comparison; Python source/tests; generated plots.

**Observed simulation metrics:** no-check 62.125% success, retry 79.000%, verify-all 100.000% (idealized audit), selective 85.125%. Mean tool calls: 3.00, 3.29875, 6.13063, 4.11 respectively.

**Not conducted:** real-model inference, independently administered public benchmark scores, deployed MCP evaluation, actual model-token cost experiments, external peer review.

**Not claimed:** verified uniqueness/novelty against 2025-2026 papers, production-grade agent reliability, equivalent correctness to verify-all, or a peer-reviewed publication.

**Potential extensions:** Real LLM action selection is implemented in a harness with mock-model tests; the notebook and model backend are not part of the v1 experimental evidence.

**What is permitted to say publicly:** This is an unreviewed working-paper release documenting a reproducible synthetic agent-workflow verification experiment, with code available for independent examination.
