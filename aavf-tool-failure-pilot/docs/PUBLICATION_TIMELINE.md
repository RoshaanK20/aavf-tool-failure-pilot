# Accurate public status and release sequence

**Pilot implemented:** November 10, 2026, according to the manuscript and repository logs.

**Do not state 'I worked on this for a month'** unless you really worked on the project for that period and can support the claim.

Appropriate terminology:
- Code release: 'controlled simulation pilot', 'preliminary experiments', 'reproducible open research prototype' once a suitable license is selected.
- Manuscript: 'working paper' or 'preprint' if shared publicly, depending on platform classification.
- Peer-reviewed publication: only after acceptance by a peer-reviewed journal or conference.

Recommended release order: audit -> author details -> license -> code repository -> manuscript dissemination (rights checked) -> LinkedIn summary with verified links.
